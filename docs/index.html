Features

練習記録

日々の練習内容や、セットマッチの結果を簡単に記録。直感的なインターフェースで入力をサポートします。

統計・分析

蓄積されたデータから、自分の成長を視覚化。弱点の把握やモチベーションの維持に役立ちます。

HUD UI

プレイ中に邪魔にならない、洗練されたデザイン。スマホを操作する時間ではなく、キューを振る時間を大切に。

Support & Privacy

このアプリはオープンソースプロジェクトとして開発されています。バグ報告や機能要望は GitHub Issues にて受け付けています。
