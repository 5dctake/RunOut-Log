プライバシーポリシー

最終更新日：2026年8月16日（制定日：2026年2月27日）

🔒 個人情報収集なし・完全オフライン

RunOut Log（以下、「本アプリ」といいます）は、ユーザーのプライバシー情報の取扱いについて、以下のとおりプライバシーポリシーを定めます。

1. 収集する情報

本アプリは、広告配信・アプリ内課金・ユーザーアカウント機能を一切持たない、完全無料のオフライン記録アプリです。

本アプリでは、以下の情報のみをデバイス内にローカル保存します。

  • ユーザーが入力した練習記録データ（ランアウト回数、日付など）

これらのデータはユーザーのデバイス外に送信・共有されることはありません。

2. 収集しない情報

以下の情報は一切収集・利用しません。

  • 氏名・メールアドレスなどの個人識別情報
  • 位置情報
  • 広告識別子（IDFA / AAID）
  • クレジットカード情報・決済情報
  • ユーザーの行動ログ・統計データ（クラッシュレポートを含む）

3. 第三者サービスの利用

本アプリは、現在いかなる第三者 SDK（広告・分析・課金）も使用していません。

4. 情報の第三者提供

ユーザーの同意を得ることなく、いかなる情報も第三者に開示・提供しません。

5. お子様のプライバシー

本アプリは個人情報を収集しないため、年齢に関わらずすべてのユーザーが安心してご利用いただけます。

6. プライバシーポリシーの変更

本アプリは、必要に応じて本プライバシーポリシーを変更することがあります。変更した場合は、本ページおよび GitHub リポジトリにて告知します。

7. お問い合わせ

本ポリシーに関するお問い合わせ、またはアプリの不具合報告等は、以下のリポジトリの Issue までご連絡ください。

  • 開発元：5dctake
  • サポート：GitHub Issues
