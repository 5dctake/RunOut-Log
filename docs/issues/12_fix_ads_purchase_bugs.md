# Issue #12: 広告と購入サービスのバグ修正 (Bug 1-5)

## 背景
アプリのリリース後、広告が表示されない問題や、課金ユーザーに対して不要な通信が発生していることが判明しました。また、非同期処理のライフサイクル管理やメモリリークの懸念も特定されました。

## 修正内容
以下5項目のバグを修正します：
1. **AdMob初期化不備 (Bug 1, 2)**: `main.dart` で `AdService().init()` を awaiting するように修正し、広告とATTのリクエストを確実に実行します。
2. **PurchaseService のライフサイクル改善 (Bug 3)**: `WidgetRef` を `Ref` に変更し、非同期処理中にウィジェットが破棄されても安全に動作するようにします。
3. **インタースティシャル広告のタイムアウト修正 (Bug 4)**: `Timer` を使用してキャンセル可能なタイムアウト処理を実装し、メモリリークを防ぎます。
4. **バナー広告のロードガード (Bug 5)**: 広告非表示ユーザーに対して `BannerAd` をロードしないように `BannerAdWidget` を修正します。

## 完了条件
- 起動時に `AdService().init()` が呼ばれること。
- インタースティシャル広告のタイムアウトがクローズ時にキャンセルされること。
- 広告非表示ユーザーに対してバナー広告のリクエストが発生しないこと。
- `PurchaseService` のすべての引数が `Ref` （または適切な provider を介したもの）に変更されていること。
