# Issue #13: センターショット (CS) モードの追加 [完了]

## 概要
基本の練習メニューである「センターショット (CS)」を10回セットで記録・分析できるようにするため、球数選択に「CS (1球)」モードを追加する。

## タスク
- [x] 1. `input_screen.dart` の入力セレクターとラベル表示に「CS / 1球」を統合する
- [x] 2. `record_screen.dart` の TabBar コントローラーを5分割に拡張し、「CS」タブを追加する
- [x] 3. `graph_screen.dart` の TabBar コントローラーを5分割に拡張し、「CS」タブを追加する
- [x] 4. `flutter analyze` による静的検証を行い、ビルドエラーがないことを確認する

## 実装結果
- `ballCount` が `1` のレコードをセンターショット用の練習履歴データとして処理するように実装。
- **入力画面**: `SegmentedButton` で「CS」を選択可能にし、カードには「センターショット モード」と大きく表示させて成否の入力を行えるようにした。また、セレクターのタイトルを「練習種目 / 球数」に変更。
- **履歴画面**: TabBar の長さを 5 に変更し、左端に「CS」タブを追加。日付・セット成績・100回ブロックごとの履歴が正常に閲覧・スワイプ切り替え可能。
- **分析画面**: 履歴画面と同様に TabBar を 5分割に変更し、「CS」の練習データに基づいた100回ブロック推移・日別・月別・年別の折れ線グラフがすべて正しく表示されるように統合完了。
