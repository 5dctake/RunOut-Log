## プロジェクト概要
RunOut Logは、ビリヤードプレイヤーが日々の練習を記録し、自身のスキル向上をデータで可視化するためのアプリケーションです。

### 🚀 最新バージョン (v1.3.1) の主な変更点
- **「フレッシュ×爽やか」クリーン・メディカルデザインへの刷新**: サイバーパンク調のHUDテーマから、スカイブルー基調で清潔感・信頼感のあるプロフェッショナルなライトテーマへUIを全面的にリニューアルしました。
- **完全無料化（広告・課金機能の完全廃止）**: 煩わしいバナー/インタースティシャル広告や課金機能をすべて削除し、すべてのユーザーがすべての機能を完全に無料で利用できるようになりました。
- **センターショット (CS) モードの追加**: 基本メニューである「センターショット（1球）」を記録・分析できるようになり、タブを「CS, 2球, 3球, 4球, 5球」の5分割に拡張しました。
- **UI/UX の改善**: 球数選択を segmented UI に変更し、入力中の種目切り替え時に誤破棄を防ぐ警告ダイアログを追加しました。

### 🚀 過去のバージョン
- **v1.1.0**: 広告表示やアプリ内課金のバグ修正および起動パフォーマンスの最適化。
- **v1.0.4 - v1.0.5**: iOSでの起動フリーズ解消と広告表示の安定化（Zero-Delay Startupの導入）。
