## プロジェクト概要
RunOut Logは、ビリヤードプレイヤーが日々の練習を記録し、自身のスキル向上をデータで可視化するためのアプリケーションです。

### 🚀 最新バージョン (v1.1.0) の主な変更点
- **広告および購入機能の完全修正**: 広告表示、ATTリクエスト、購入情報の同期にまつわるすべてのバグ（計7点）を修正し、安定性を大幅に向上させました。
- **起動パフォーマンスの改善**: Hive の初期化位置を最適化し、アプリの起動とデータの読み込みをよりスムーズにしました。
- **UI/UX の整合性向上**: アプリ内のバージョン表示を統一し、広告表示の挙動を改善しました。

### 🚀 過去のバージョン (v1.0.4 - v1.0.5)
- **広告表示の安定化**: iOS 14+ での不具合修正。
- **起動フローの高速化**: Zero-Delay Startup の導入。
