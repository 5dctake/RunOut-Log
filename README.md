## プロジェクト概要
RunOut Logは、ビリヤードプレイヤーが日々の練習を記録し、自身のスキル向上をデータで可視化するためのアプリケーションです。

### 🚀 最新バージョン (v1.0.4) の主な変更点
- **起動フローの高速化**: 起動時のフリーズを解消し、即座にスプラッシュ画面が表示される「Zero-Delay Startup」を導入しました。
- **広告表示の安定化**: iOS 14+ での広告表示の不具合（ブラックアウト）を修正し、安定したプレイアブル広告の配信をサポートしました。
- **iOS 17+ 対応**: iOSの新しいウィンドウシステムとの干渉を解消し、動作安定性を向上させました。
